# Codex AGENTS.md 与 Skills 整理资料包

## 文件怎么用

- tutorial.md：完整教程，包括匿名实测范围、数据与解释。
- complete-prompt.txt：教程原稿完整提示词，6,829 字符。
- single-project-prompt.txt：单项目完整试用版，在原稿要求前补充执行参数。
- all-projects-apply-prompt.txt：全量正式修改版，填写真实项目范围后再使用。
- quick-prompt.txt：小红书图 11 的快速试用版本。

TXT 内容直接发到 Codex 对话里，不要把整段放回长期 AGENTS.md，也不需要安装新的 Skill。单项目试用版默认生成独立候选文件；全量版明确授权备份后修改所列正式文件。

完整基础提示词与原稿一致。单项目版和全量版只在前面增加本次运行参数，完整基础要求没有删减。两种成套版本默认不启动子 Agent。

先看运行结果中的 README.md、项目结果.md、变化表.md、检查与恢复.md。文件生成、正式应用、实际任务验证是不同状态；字符减少不是 Token 或费用节省证明。
